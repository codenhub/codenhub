# Origem das skills

Quando você instala uma skill em um projeto e a compartilha com sua equipe, a atribuição de autoria precisa acompanhá-la. Esta página registra a origem e o contexto de licenciamento das skills distribuídas pelo `@codenhub/skills`, para você conferir o que está adotando antes de redistribuir ou modificar esse material.

Os termos legais do pacote estão em [NOTICE](../../NOTICE). Cada skill adaptada também traz a atribuição de autoria e o texto da licença original no próprio diretório, em `NOTICE` e, quando a licença é longa, em `LICENSE`, para que ambos sejam copiados mesmo quando o instalador copia só aquela skill. No nosso exemplo com `brainstorming` e `test-driven-development`, os avisos MIT acompanham cada cópia instalada para Claude e Codex.
