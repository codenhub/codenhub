# 0.2.0

## Added

- `audit`, which audits and reviews code, pull requests, and packages and classifies every finding the same way. It replaces `caveman-review`.
- `design`, which guides visual and interface design in any medium: hierarchy, typography, space, color, interaction, and interface motion. It replaces `frontend-design`.
- `naming`, which generates, researches, and judges names for products, packages, tools, and code identifiers, and verifies each presented name's meaning, pronunciation, and collisions.
- `branding`, which builds brand strategy and identity systems, from positioning and voice to visual identity, guidelines, and presentations.
- `logo-design`, which designs logos from written concepts to outlined SVG files and usage rules, with a script that outlines lettering with the font's kerning.
- `motion-graphics`, which storyboards, animates, and renders videos frame by frame from a seekable timeline, with any encoder the environment has.
- `ponytail` and `ponytail-review`, which keep code to the simplest solution that works and review a diff for over-engineering.
- `babysit-pr`, which sees a pull request through CI and review until it is ready to merge, fixing failing checks and answering reviewers.
- `project-template`, which creates, syncs, and adopts projects built on the shared project template.
- `playful-tone`, which gives docs and public text a natural, playful tone in any language.
- **Stable.** The package is no longer experimental.
- The installer covers Cursor, Gemini CLI, Copilot, Windsurf, Trae, Cline, Kiro, ZCode, and the cross-harness Agent Skills location (`.agents/skills`). Harnesses that read the same directory get one copy of each skill.
- A CLI guide, a skill format and catalog page, and a provenance page.

## Changed

- **Breaking.** Node.js 24 or newer is required, up from 18.
- **Breaking.** Codex skills install to `.agents/skills` in the workspace and `~/.agents/skills` globally, where Codex now reads them, instead of `.codex/skills` and `~/.codex/skills`. Skills installed by 0.1.0 stay in the old directory until you delete them.
- `writing-skills`, `agents-md-improver`, `subagent-specialist`, `test-driven-development`, `brainstorming`, `caveman`, and `caveman-commit` are rewritten or revised. `writing-skills` is organized around the Agent Skills specification's rules and an evaluation procedure.
- Bundled skills no longer name other skills, since the user may not have them installed.

## Removed

- **Breaking.** `frontend-design`, replaced by `design`, and `caveman-review`, folded into `audit`. The installer does not remove a skill's old directory, so delete `frontend-design` and `caveman-review` from each skills destination by hand.
