# Uso

Estas guías terminan la pantalla de ajustes que empezó en [Construir una pantalla](../concepts.md). Lee las siete primeras en orden: cada una añade una parte de la pantalla y da por hechas las anteriores. Las tres últimas son páginas de consulta; las guías te enviarán a ellas cuando necesiten la tabla completa, y puedes volver siempre que necesites un valor por defecto o una regla.

Guías, en orden:

1. [Botones](./buttons.md): la acción destructiva de la zona de peligro, botones de icono, tamaños, enlaces con aspecto de botón y estados deshabilitados, además de cómo cargar iconos.
2. [Formularios](./forms.md): el formulario de perfil, con etiquetas, pistas, errores de validación, un input con un icono o un prefijo fijo, un select y toggles de checkbox, radio y switch.
3. [Feedback](./feedback.md): lo que muestra la pantalla mientras guarda y después: un botón de carga, una alerta de éxito, un badge del plan, un placeholder de carga y una barra de uso de almacenamiento.
4. [Tooltips](./tooltips.md): texto de ayuda junto a un campo de formulario, cómo conectarlo para quienes usan teclado y lector de pantalla, y dónde puede quedar recortado un tooltip.
5. [Temas](./theming.md): modo claro y oscuro, reemplazar la paleta con los colores de marca y definir una intención propia, con las tablas completas de tokens de color y tokens base.
6. [Estéticas](./aesthetics.md): los seis aspectos opcionales, lo que cambia cada uno y sus límites.
7. [Clases solo](./solo.md): pintar una estética sobre un componente de otra librería.

Páginas de consulta:

- [Composición](./composing.md): las reglas completas para combinar intención, presentación y elevación, los valores por defecto de cada componente y qué ejes lee cada uno.
- [Personalización](./customizing.md): tokens de presentación y de material, controles de las estéticas, las seis variables públicas de componente, la paleta generada y los helpers de composición para construir tus propios componentes.
- [Contenido y layout](./content-and-layout.md): todos los helpers de layout, la escala tipográfica, tarjetas y paneles, tablas, citas, código y teclas.

Cuando termines, [Accesibilidad](../accessibility.md) reúne lo que el CSS hace por ti y lo que tu aplicación todavía les debe a sus usuarios.
