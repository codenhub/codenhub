# Usage

These guides assume the [Concepts](../concepts.md) mental model: intent, presentation, and aesthetic as three independent axes, resolved through tokens a component reads.

- [Composing](./composing.md): Combining the three axes on a component, the axis-support matrix, and elevation modifiers.
- [Theming](./theming.md): The color, intent, and foundation token reference.
- [Customizing](./customizing.md): The presentation and material token reference, aesthetic knobs, and defining a custom intent.
- [Aesthetics](./aesthetics.md): Each shipped aesthetic in depth, including its documented exceptions.
- [Buttons](./buttons.md)
- [Forms](./forms.md)
- [Feedback](./feedback.md)
- [Tooltips](./tooltips.md)
- [Content and layout](./content-and-layout.md): Layout helpers, tables, quotes, code, surfaces, and typography utilities.

## Supported surface

A class, component, and axis combination is supported when this documentation describes it and the package playground demonstrates it. Undocumented and undemonstrated combinations may still produce CSS, but are not maintained behavior. Playground variant matrices are the exhaustive demonstrations; small examples elsewhere illustrate usage without widening that contract.
