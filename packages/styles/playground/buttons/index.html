Chip-sized

p-xs and its alias dense are the one padding step that also drops the --control-height floor, so a button can sit inside a table cell or a dense toolbar. Every other size and padding class keeps the floor. The icon variant sizes its own glyph — the package leaves glyph dimensions to the consumer.
