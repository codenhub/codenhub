UI fixtures

Surfaces

Containers and the rules between them. Cards float above the layout, panels sit flush against it, and both read intent, presentation, and material. Each grid is one row per presentation and one column per intent, preceded by a cell with no intent class at all.

Cards

A card with no presentation class is a bare, edged container with a low elevation. Only an explicit fill tints it.

Interactive

.interactive adds a pointer, a hover lift, and a focus ring. It is styling only — use a real control and give it a name.
