Input types

Every text-like type maps onto .ipt for the shared chrome and nothing else. No type ships an icon; date and datetime-local keep the browser's native picker.

Icons

Icons are not shipped. .input-group is the wrapper that owns the field box, so any icon element sits flush beside the control — a leading child for a leading icon, a trailing child for a trailing one. The glyphs below are inline <svg> ; a real project would more likely reach for @codenhub/icons or another set.
