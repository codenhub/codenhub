# 0.2.1

## Added

- The package declares `"sideEffects": false`, so a bundler drops it entirely from a build that imports nothing from it.
- A documentation walkthrough, from a first light and dark toggle to a production setup, with CSS examples, a table of every option and its default, a Vite example for the pre-paint script, React and Tailwind CSS setup, and a troubleshooting page.

## Changed

- Documentation pages are reorganized around the walkthrough: `docs/tokens-and-persistence.md` is replaced by `docs/tokens.md` and `docs/persistence-and-sync.md`, and `docs/ssr-and-pre-paint.md` by `docs/preventing-the-flash.md` and `docs/frameworks.md`. Update any link that pointed at the old pages.
