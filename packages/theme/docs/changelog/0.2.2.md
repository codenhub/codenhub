# 0.2.2

## Added

- The API reference page opens with a one-line summary of the package.

## Changed

- Member headings on the API reference page name their owner, such as `Theme › set`, so each member's anchor is `#theme--set` rather than `#set`. Update any link that pointed at a member's old anchor; anchors of the top-level exports are unchanged.
- Interface signatures on the API reference page list their members, and each **Throws** entry names the error type, `Error`.
