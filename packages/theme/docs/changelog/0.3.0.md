# 0.3.0

## Added

- `set(name, { followSystem: true })` saves a choice that applies `name` or its `pairedTheme`, whichever has the operating system's color scheme, and switches between them when the operating system does. Apps with theme families no longer need a second store and a rebuilt manager to follow the system. The pre-paint script and other tabs apply the same variant. ([#583](https://github.com/codenhub/codenhub/issues/583))
- `theme.followsSystem` reports whether the saved choice follows the system, and `ThemeSetOptions` types the new `set()` options.

## Changed

- A choice that follows the system is saved in `localStorage` as `{"name":"…","followSystem":true}` instead of a bare theme name. Fixed choices are still saved as bare names. A version before 0.3.0 ignores the new form and falls back to the system theme, so rolling an app back after users chose a following theme loses those users' choice.
