# 0.2.3

## Added

- The README and every guide are available in Brazilian Portuguese and Spanish.
- The docs state the oldest browsers the published package runs on, Chrome 93, Firefox 92, and Safari 15.4, what fails below them, and how to support older browsers by transpiling.
- The npm package lists `keywords`, so searches such as "dark-mode" and "prefers-color-scheme" find it.

## Changed

- The guides are rewritten as one walkthrough, from a first toggle to a production setup, with the accessibility work a theme switcher needs.
- The npm `homepage` points to the documentation site, https://codenhub.dev/packages/theme/.

## Fixed

- The docs say when a `className` function's invalid class throws: the first time any class is needed, usually in `init()` or `getPrePaintScript()`, not only when that theme is applied.
- The docs no longer promise that clearing a color input resets an accent token, which a color input cannot do; they suggest a reset button that calls `setTokens({})`.
- The troubleshooting entry for a theme that ignores the operating system covers a choice the browser could not save.
- The docs say that a token value the browser rejects stays in place across theme changes until it is replaced.
- The `themes.md` menu example type-checks under `strict`.
