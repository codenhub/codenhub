# 0.4.1

## Changed

- Nothing a consumer imports has changed: the code is the same as 0.4.0's, so upgrading needs no action. The release records its size for each export imported alone, and its bytes by source file, function, and class member, for the package index to show where they go.
- The `homepage` of the manifest, which npm links, is the package page on codenhub.dev, where it was the package's directory on GitHub.
- The reference pages describe index signatures, overloads, and the block tags of members more fully, and their anchors no longer change between builds.
