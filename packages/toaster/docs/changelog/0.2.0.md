# 0.2.0

Pre-1.0 public API overhaul flattening the dispatcher surface, integrating first-class Promise lifecycles, and introducing awaitable thenable dialogs.

## Added

- Pre-configured browser singletons: top-level `toast` and `dialog` exports are available for zero-boilerplate use across applications.
- Callable root dispatcher: `toast("message", options?)` dispatches neutral notifications without requiring an arbitrary severity level or custom DOM nodes.
- Semantic shorthand dispatchers: `toast.success()`, `toast.error()`, `toast.warning()`, and `toast.info()`.
- First-class Promise lifecycle binding: `toast.promise(promise, options)` tracks pending operations, handles success and error transitions with custom message formatters, automatically re-arms auto-dismiss timers, and returns the underlying Promise value.
- Structured content and inline actions: toasts support `title`, `description`, and `action: { label, onClick: (event, handle) => void }` directly in options.
- Automated API reference documentation: compiled directly from TypeScript declarations and source TSDoc under `docs/reference/`.

## Changed

- Flattened public API: removed nested dispatcher namespaces (`toaster.semantic`, `toaster.loading`, `toaster.custom`, `toaster.interactive`) in favor of direct methods on `toast` and `dialog`.
- Thenable interactive handles: `InteractiveToastHandle<T>` returned by `dialog.confirm()`, `dialog.prompt()`, and `dialog.alert()` implements `PromiseLike<T>`. Calling `await dialog.confirm(...)` directly resolves to the primitive `boolean` (`string | null` for prompt, `void` for alert) instead of an object reference, while retaining access to `.dismiss()`, `.settled`, and `.state`.
- Standardized error vocabulary: unified all error terminology to `error` (e.g. `toast.error()`, `type: "error"`, `errorBg`/`errorEdge`/`errorBtnBg` tokens), replacing legacy `"danger"` and `"destructiveBg"`.
- Standardized boolean options: renamed `isDismissable` to `dismissible` (with `closeButton` supported as an alias) and `shouldAutoDismiss` to `autoDismiss`.

## Removed

- Legacy nested namespaces: `toaster.semantic`, `toaster.loading`, `toaster.custom`, and `toaster.interactive` are removed.

## Fixed

- Re-armed auto-dismissal on promise loaders: updating a loading toast to a success or error state automatically re-arms the auto-dismiss timer instead of leaving the notification on screen indefinitely.
- Layout rebuilds on toast updates: updating message and title properties preserves layout structure and secondary descriptions when transitioning between simple and structured formats.
