# 0.4.0

## Added

- `@codenhub/toaster/dialog` exports `dialog` and `createDialogs`. While one of its dialogs is open, the toasts of every toaster rendering into the same parent move into it, as before.

## Changed

- Dialogs are no longer part of `@codenhub/toaster`, so an app that only shows toasts no longer bundles them: `toast("…")` alone costs about 9.1 KB gzipped, down from 12.7 KB. `dialog` and `toaster.dialog` are gone from the main entry; import `dialog` or `createDialogs` from `@codenhub/toaster/dialog`. The `confirm`, `cancel`, `submit`, and `ok` labels move to `DialogsConfig.labels`, a toaster's `className` and `destroy()` no longer affect dialogs, and `DialogDispatcher` is renamed `Dialogs`.
- String content passed to `toast.custom()`, the `content` option, or `update({ content })` renders as plain text, so markup in it shows literally. Pass a DOM node or a node factory for formatted content. The package no longer uses any HTML-parsing sink, so a Trusted Types policy needs nothing for it.
- Colors are set with `--toast-color-*` CSS custom properties in your own CSS. The `tokens` and `nonce` options and the `ToastTokens` type are removed, and the package injects no `<style>` element, so a strict `style-src` policy needs no nonce.

## Fixed

- Dismissing a queued dialog no longer moves the toasts out of the dialog that is still open.
- Submitting a prompt with Enter no longer activates the element that opened it when focus returns there.
- A dialog whose element was removed, or whose `body` was replaced, is recreated instead of every later dialog failing.
- An update that only changes a toast's text keeps its action and dismiss buttons, so focus on them is kept.
- A dismissed toast restores focus only when its removal lost it, not when focus moved elsewhere during the exit animation.
- An update from an `onShow` subscriber no longer renders the content twice.
- `destroy()` after `clear()` finishes leaving toasts immediately, and a toast dismissed during its entrance animation can still have its exit cancelled.
