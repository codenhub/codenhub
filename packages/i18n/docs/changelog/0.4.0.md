# 0.4.0

## Added

- The README and guides are available in Brazilian Portuguese and Spanish.

## Changed

- **Breaking.** Node.js 26 or newer is required, up from 24. Installing on Node.js 24 or 25 makes npm and pnpm warn, or fail with `engine-strict` on; upgrade Node.js to 26. Browsers and Web Workers are unaffected.
- **One `t()` call fills at most 100 arguments**, counting those inside plural and select forms, and leaves the rest as written. A UI sentence never comes close; the limit keeps a huge fetched message from costing one formatting step per placeholder on every render. A plural form's `#` is formatted once however often the form repeats it.
- **An overtaken `init()` or `setLocale()` resolves when its loading fails**, as it does when its loading succeeds. Only the latest call's failure rejects, so a language picker clicked twice no longer reports an error for a locale the visitor already left.
- **The browser binding matches a saved locale you no longer configure**, such as `pt-PT` once only `pt-BR` remains, like a browser preference, where it ignored it and detected again. The saved value is left as it was.
- **`matchLocale()` skips `und`**, the undetermined language, with any subtags, where likely subtags made it match English.
- **The browser binding skips customized built-in elements**, such as `<button is="cart-button">`, and their content, as it skips elements whose tag has a dash: the component owns that text.
- The guides are rewritten around one running example. The canonical-redirect examples skip static files, and the static-site redirect script matches a saved locale and skips `und` as `matchLocale()` does.
- The manifest lists npm keywords, and the README links the license.

## Fixed

- Parsed messages could exhaust a server's memory: every manager in a process shares the parse cache, which held up to 10,000 messages of any length, and the parser kept about 30 bytes per character of each. On Node.js 26, 400 cached messages of 100,000 characters held 1.3 GB, and 2,000 exhausted the heap. The cache is now also bounded at 5,000,000 characters, and 2,000 such messages hold about 4 MB.
- The warnings for a missing key and for an invalid message wrote line and paragraph separators in the key as they are, so a key from outside input could break a log line. They are now escaped.
