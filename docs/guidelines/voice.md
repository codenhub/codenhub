# Brand voice

This document proposes how Coden sounds and the strategy behind it. It is a draft: the positioning rests on assumptions listed below, and no tagline has been chosen. The visual identity, which is decided, is in [`identity.md`](identity.md); how the name is written is in [`branding.md`](branding.md).

## Positioning

For small and growing businesses that need software built well and do not have an engineering team of their own, Coden is the development agency that builds apps and websites on its own published open-source foundation, so clients can see the quality of the work and the tools behind it before they hire.

Assumptions to confirm:

- The main clients are small and medium businesses and founders, not large enterprises.
- The reason to believe is CodenHub: Coden's own tools and packages are public at `codenhub.dev`, so the way Coden builds can be inspected.
- Coden's marketing, SEO, infrastructure, and security work supports the software work rather than being sold as a separate offer.

## Brand idea

**Code for any n.** Whatever the client needs is the `n`; Coden writes the code for it. The logo states it as `code[n]`, and the name carries it twice: code + _mugen_ (無限, "infinite"). The idea has two sides that the personality has to hold together: the rigor of code, which is exact and does what it says, and the openness of n, which can be anything.

| ----------------------- | ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------- |

## Voice principles

Each principle shows the same real sentence in Coden's voice and in a nearby wrong voice.

### Say exactly what happens

Coden writes the way good code reads: specific, with nothing implied.

- Coden: "The site is down while we move it to the new server. It will be back by 14:00."
- Wrong, vague: "We're experiencing some temporary issues and are working hard to resolve them."

### Plain words first, the technical word when it is needed

Explain in the client's words, then name the technical term once, so they can use it later.

- Coden: "Your pages will load from servers close to each visitor, through a CDN."
- Wrong, jargon: "We'll leverage edge-cached CDN delivery to optimize TTFB."

### Play in one detail, never in the facts

A playful turn is allowed once per piece, in a heading, an example, or a sign-off, and never in prices, dates, errors, or commitments.

- Coden, empty state: "Nothing here yet. Your n goes here."
- Wrong, joking about a failure: "Oops! Our code took a coffee break. ☕"

### Confident without claims

Show the work, a number, or a link instead of an adjective.

- Coden: "We built the booking app for Clínica Aurora; it has handled 4,200 appointments since March."
- Wrong, inflated: "We craft world-class, cutting-edge digital experiences."

The examples above use an invented client; replace them with real case studies when they are published.

Tone shifts by situation while the voice stays the same: shortest and most direct in errors and incidents, warmest in onboarding and thank-you notes, and most playful in merchandise and social posts.

## Taglines

None is adopted. Each candidate below is checked against the brand idea and against whether another agency could use it unchanged.

| Kind        | Candidate                              | Note                                                                                |
| ----------- | -------------------------------------- | ----------------------------------------------------------------------------------- |
| Imperative  | Solve for n.                           | Uses the logo's own variable; reads as a challenge to the client. Recommended.      |
| Imperative  | Name your n.                           | Invites the client to state the need; slightly cryptic without the logo next to it. |
| Descriptive | Code for any n.                        | The brand idea itself; clear, but less memorable than "Solve for n."                |
| Descriptive | n = whatever you need.                 | Clear and playful; long for small formats.                                          |
| Provocative | Every business has an n.               | Strong opening line for a website hero; weaker as a sign-off.                       |
| Benefit     | Your idea, indexed.                    | Clever, but "indexed" also suggests search engines.                                 |
| Imperative  | Bring the n. We'll write the code.     | Clear about the offer; two sentences make it heavy.                                 |
| Descriptive | Apps, sites, and the code behind them. | Accurate, but any agency could sign it.                                             |
| Provocative | Infinite code, finite deadlines.       | Plays on mugen and promises delivery; the contrast form is one to use sparingly.    |
| Benefit     | Built to run. Built to last.           | Generic; rejected.                                                                  |
| Imperative  | Pick an n.                             | Short and playful; too casual for the serious side.                                 |
| Descriptive | Software, any size.                    | Plain; loses the brand idea.                                                        |
| Provocative | There's code for that.                 | Echoes a well-known phone ad; rejected.                                             |
| Benefit     | From n to shipped.                     | Shows the process; "shipped" is jargon for some clients.                            |
| Descriptive | Coden builds your n.                   | Clear and owned; plain rather than memorable.                                       |
| Imperative  | Start at zero.                         | Nods to zero-indexing; unclear to non-developers.                                   |

Recommendation: "Solve for n." for the website hero and social profiles, with "Code for any n." as the plain explanation beneath it where one line is not enough. Before adopting either, a qualified person should run a trademark search in Brazil and in any other market where Coden sells, and a native speaker should check the line in each language the site will use; this draft checked neither.

## Messaging

- **One line:** Coden builds apps and websites on open-source tools it publishes itself.
- **25 words:** Coden is a development agency that builds apps and websites for growing businesses, using CodenHub, its open-source foundation, so every client starts from tested code.
- **60 words:** Coden builds apps and websites for businesses that need software done well and do not have engineers of their own. We start every project from CodenHub, the open-source toolkit we build and publish at codenhub.dev, so clients can inspect how we work before they hire us. Alongside development, we handle the hosting, search, and security that keep the software running.

Key messages, each with the proof to show beside it:

1. Coden's foundation is public. Proof: the packages and documentation at `codenhub.dev`.
2. Coden builds whatever the n is: apps, websites, and internal tools. Proof: the case studies at `coden.agency`.
3. The work keeps running after launch. Proof: the hosting, search, and security services and their response times.
4. Clients talk to the people who write the code. Proof: the team named on each project.

## Copy patterns

Generated and agency copy overuses a few constructions until they become noise: "X, not Y" contrasts, "Less X. More Y." pairs, two-fragment slogans, lists of three joined by middots, and small uppercase labels above headlines. Coden uses each at most once across a site or campaign, and only where it is the clearest way to say the thing. Write each line as a plain sentence first, and keep that version when it says the same.
