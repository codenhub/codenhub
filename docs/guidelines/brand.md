# Brand

CodenHub is part of the Coden brand, which is published at [coden.agency/brand](https://coden.agency/brand): the brand model, how to write "Coden" and "CodenHub", the visual identity, the voice, and the artwork and fonts, each file listed with its size and SHA-256 in [`index.json`](https://coden.agency/brand/index.json). It is not copied here, because a copy drifts from its source and a link does not.

This repository adds only what is specific to it:

- **Package names and titles** follow [Package naming](package-naming.md): when a title carries "CodenHub", the words that describe a package, and each package's display name.
- **Where a package places a brand file** is that package's own decision, declared in its manifest, as [Tooling](../tooling.md#asset-placement) describes.
- **The voice of public package docs** is the [documentation guidelines' voice](documentation.md#voice), with what a package doc adds to it in [Public docs writing](public-docs-writing.md).
